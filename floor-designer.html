  1. In Home Assistant, open the File editor or Samba share add-on and create the folder /config/www/floorplan/. (If www did not exist before, restart Home Assistant once.)
  2. Upload the floor images (floor-1.png, floor-2.png… or .svg for the flat look) there.
  3. You picked button-card: install it once from HACS → Frontend → search “button-card” → Download, then refresh the browser.
  4. Go to Settings → Dashboards → Add dashboard → New dashboard from scratch and open it.
  5. Click ✎ Edit → ⋮ → Raw configuration editor, replace everything with the YAML above, then click Save.
  6. Tap a light, switch or plug to toggle it. Press and hold any device to open its details.
